# 任务计划：菜单栏截图与剪贴板

> 对应 [PRD-001](prd/PRD-001.md) V1.0
> 日期：2026-10-30
> 核对：2026-11-11，同步已确认的工具栏、图标和权限说明。
> 用途：保留实施顺序和人工验收清单；以下条目是验收要求，不是已完成记录。自动化测试通过不能替代实机验收。

## 1. 完成定义

下面四件事同时成立，这一版才算完成：

1. 平时只有菜单栏图标。底栏要按 ⌘⇧V 或「打开历史」才出现，用完消失。
2. 复制过的文本、图片、链接、颜色能找回，点一条能贴回刚才的 App。
3. 区域、窗口、全屏截图后，能标注、打马赛克，再复制、当场保存、钉住或丢弃。保存不依赖设置里的文件夹。
4. 容量默认 200 MB，可改档位。超过上限删最早的。权限不够时有说明，不是静默失败。

工程名为 `CVEtool`，应用显示名为「截图剪贴板」，界面中文。打包应用最低系统为 macOS 15.2；构建命令和工具要求见 [README](../README.md)。

## 2. 顺序

不要并行开截图和历史两摊，再最后拼。历史是截图结果的去处，先让历史能记、能找、能贴，再把截图接上去。

| --- | --- | --- | --- |

## 3. 任务

完成标准都用用户看得见的结果来写。一条没达到，就不算完成。

### M1 壳

**T1 建菜单栏工程**
- 做一个只出现在菜单栏的应用，Dock 里没有图标。
- 应用文件采用绿色底板的 04 回形夹图标，菜单栏使用同一轮廓的黑白模板图标。
- 完成标准：启动后屏幕底部没有条，Dock 没有图标。退出后图标消失。

**T2 菜单**
- 菜单项和快捷键与 PRD US-01 的线框一致：区域截图、窗口截图、全屏截图、打开历史、设置…、退出。
- 默认快捷键 ⌘⇧1、⌘⇧2、⌘⇧3、⌘⇧V，前三项开始对应截图，最后一项唤出或收起历史。
- 完成标准：点图标只开这个菜单，不弹出历史。

**T3 设置窗口骨架**
- 有通用、存储、权限三块。存储区只有容量档位和已用，没有「截图另存到」。
- 开机时启动可以开关，默认开。
- 完成标准：打开设置，看不到保存位置。关掉开机启动后，这次仍在跑。

### M2 记得住

**T4 记住复制的内容**
- 应用运行时，记住文本、图片、链接、颜色。新的在最前。
- 完全相同的不重复堆，只移到最前。空内容不记。只有文件的不记。
- 链接和颜色值不要同时出现在「文本」里。
- 完成标准：复制「明天下午三点，会议室 B」后，重启应用，这句话还在最前。再复制同一句，仍只有一条。

**T5 容量**
- 档位 50 / 100 / 200 / 500 MB / 1 GB，默认 200。
- 新条目放不下时，从最早的删，直到放得下。单条本身大于上限时不写入，并提示「这一张超过容量上限，没有放入历史」。
- 把上限改小到已用以下时，立刻删最早的，直到已用不超过新上限。
- 完成标准：按 US-08 的四个验收场景各走一遍。

### M3 找得到

**T6 按需唤出底栏**
- 「打开历史」和快捷键都能唤出。出现在鼠标所在屏幕的底部。
- 再按快捷键、Esc、点条外面，都收起。已经开着时再唤出，改为收起。
- 底栏默认不抢走焦点。
- 完成标准：平时底部是空的。从备忘录按快捷键唤出后，备忘录仍是当前 App。点条外面，条消失，且没有粘贴。

**T7 筛选、搜索、预览**
- 筛选为全部、文本、图片、链接、颜色、截图。默认全部。
- 一条横条，放不下就横向滚动。图片只显示小缩略图。停在图片上才出大预览，移开就消失。
- 搜索匹配文字、链接和色值。没有历史时显示「还没有历史」。没有匹配时显示「没有匹配的内容」。
- 右侧显示已用 / 上限。点数字打开设置，不在条上改档位。
- 完成标准：一张本应用截的图能在「全部」「图片」「截图」里看到。普通图片不出现在「截图」里。

**T8 点一条就贴回去**
- 辅助功能已授权：写入剪贴板，粘贴到唤出之前的 App，底栏收起。
- 未授权：仍写入剪贴板并收起，提示内容已复制、辅助功能未授权，可手动粘贴。
- 完成标准：在备忘录里唤出历史，点一段文字，这段文字出现在备忘录里。

**T9 权限说明**
- 设置里显示屏幕录制和辅助功能是已授权还是未授权，未授权时能打开系统设置。
- 屏幕录制授权后按当前版本提示完全退出并重新打开；辅助功能授权后可先返回重试，仍不生效时重开。
- 快捷键可以改。改成不能用的组合时不保存，提示「这个快捷键不能用」。
- 完成标准：未授权辅助功能时点一条，会看到内容已复制及去授权提示。

### M4 截得下

**T10 三种截图**
- 未授权时，三个入口仍可点，但不进入截图。请求屏幕录制权限，并引导到系统设置授权。
- 区域：拖选后捕获画面，四边和四角可改大小，未选工具时可移动已截下的图像，旁边显示宽高。移动、缩放不重新抓取桌面；拖得太小则不成选区。
- 窗口：点窗口即选区，不拖框。
- 全屏：鼠标所在屏幕整屏为选区，工具栏在该屏幕底部居中。
- 区域和窗口的工具栏贴选区下沿并优先右对齐，贴不下就改到上沿或避让屏幕边缘。
- 截图时底栏必须隐藏。截图中按历史快捷键，不打断截图。
- Esc 取消，不产生历史。
- 完成标准：按 US-05 的四个场景走一遍。多屏幕时只截鼠标所在的那一块。

**T11 标注**
- 工具：箭头、矩形、椭圆、文字、马赛克、高亮。进入时不预选工具。
- 工具栏使用纯图标及中文悬停提示。选中标注工具后展开红、蓝、黑、黄、白五色色板；选中马赛克后展开大小滑条。没有任意取色器、线条粗细或字体面板。马赛克涂过的内容在最终图上不可读。
- 撤销、重做按笔计算。没有可撤的笔时，按钮不可用。
- 未点出口之前不合成最终图。
- 完成标准：涂掉一行手机号再复制，贴出去的图上这行不可读。撤销能去掉刚画的箭头，重做能把它叫回来。

**T12 四个出口**
- 复制：绿色对勾「完成并复制」，进剪贴板，作为截图进历史，退出。
- 保存：只弹出系统保存面板，默认文件名带日期和时间。没有默认文件夹设置。成功后文件落地，并进入历史，然后退出。取消或失败则留在标注，历史不变。
- 钉住：进入历史，留下可拖动的浮层和关闭按钮。关掉浮层不删历史。同时只钉一张，新的钉住会关掉旧浮层。
- 丢弃：红叉「取消截图」，不写文件，不进剪贴板，不进历史。Esc 取消截图；有文字输入框时先结束当前文字输入。
- 这一张大于容量上限时，历史不写入，但复制和保存文件仍可完成，并提示没有放入历史。
- 完成标准：按 US-07 的五个场景走一遍。设置里确认没有「截图另存到」。

## 4. 先不做

这些如果在实现时冒出来，记下来，不塞进这一版：

- 滚动长截图、录屏、OCR、上传、同步
- 置顶、收藏、标签、文件历史
- 任意取色器、线条粗细和字体面板（已有五色标注和马赛克大小滑条）
- 左/右竖排历史，或把底栏改回常驻
- 读取 ClipDot 已有数据
- 默认保存文件夹

## 5. 做的时候容易跑偏的地方

- 底栏如果一启动就显示，T6 不算完成。
- 点菜单栏图标如果直接弹出历史，T2 不算完成。
- 设置里如果出现保存位置，T3 和 T12 都不算完成。
- 为了省事把原图全放进底栏，预览不释放，就违背了「不要占内存」的原因。条上只放小图，停住才看大的，钉住的那张关掉就放掉。
- 权限失败如果没有任何提示，T9 和 T10 不算完成。
