# 截图剪贴板

菜单栏里的 macOS 截图和剪贴板历史工具。平时不占屏幕，需要时再唤出来。截过的图和复制过的文字、图片、链接、颜色放在同一条历史里，可以搜索找回。

源码公开。目前没有经过 Apple 公证的安装包，下载后请在本机自己构建。未公证的应用在别人的 Mac 上会被系统拦住，不能当普通安装包分发。

## 能做什么

- 只住在菜单栏，没有 Dock 图标
- 区域、窗口、全屏截图
- 标注：箭头、矩形、椭圆、文字、马赛克、高亮
- 颜色为红、蓝、黑、黄、白
- 马赛克画笔大小可调
- 截完后复制、保存、钉在屏幕上，或丢弃
- 剪贴板历史：文本、图片、链接、颜色、截图
- 搜索、按类型筛选、选中后粘贴回刚才的应用
- 容量档位默认 200 MB，超过后删除最早的记录
- 快捷键可在设置里修改

## 环境

- macOS 15.2 或更高
- Xcode 或 Swift 6 命令行工具

## 构建和运行

```bash
git clone https://github.com/herschel001/CVEtool.git
cd CVEtool
swift test
bash scripts/package-app.sh
open build/CVEtool.app
```

`swift run CVEtool` 也可以直接跑，但权限和菜单栏行为以打包后的 `build/CVEtool.app` 为准。

打开后看屏幕右上角的取景框图标。点图标是截图菜单。历史用「打开历史」或默认快捷键 `⌘⇧V` 唤出，用完即走。

## 权限

第一次截图需要屏幕录制。自动粘贴需要辅助功能。

到「系统设置 → 隐私与安全性」里打开对应开关。屏幕录制打开后，必须完全退出应用再重新打开，正在运行的进程拿不到这项权限。列表里的名字是「截图剪贴板」或 CVEtool。

本机构建出来的包是临时签名。换一台电脑，或重新打包后，系统会把它当成新应用，授权需要重新点一次。要让别人下载后直接打开，需要用 Apple Developer ID 签名并公证。这个仓库现在只公开源码，没有公证过的安装包。

## 数据

历史保存在本机 `~/Library/Application Support/CVEtool`。设置保存在 UserDefaults。不上传、不同步、不读取其他剪贴板工具的数据。

开发时可以用 `CVETOOL_SUPPORT_DIR` 指定另一个目录，避免写进日常历史。

## 目录

- `Sources/CVEtoolApp/`：菜单栏、截图、剪贴板、设置
- `Sources/CVEtoolCore/`：历史存储、容量、分类、标注绘制
- `Tests/CVEtoolCoreTests/`：核心逻辑测试
- `docs/`：需求文档和设计稿
